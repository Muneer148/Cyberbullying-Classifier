# Cyberbullying Classifier

Academic NLP classification project for detecting cyberbullying-related text.

## Approach
- Text cleaning and normalization
- Tokenization, stop-word removal and lemmatization
- TF-IDF feature extraction
- Stratified train/test split
- Comparison of Multinomial Naive Bayes, Logistic Regression, Decision Tree and Random Forest classifiers
- Accuracy, classification report and confusion matrix evaluation

Academic / learning project. Results and implementation are preserved from the original notebook.
